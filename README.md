## ✦ Bismillahirrahmanirrahim

Repository ini merupakan ikhtiar digital untuk membantu pengelolaan pesantren yang lebih tertib, transparan, dan mudah diakses oleh pengurus, ustadz, santri, maupun wali santri.

> Khairunnas anfa'uhum linnas.

## 📌 Tentang Aplikasi

PPSA Management System adalah aplikasi manajemen pesantren berbasis web yang dirancang menggunakan arsitektur cloud-native modern.

### Teknologi

- GitHub Pages
- Cloudflare Workers
- Cloudflare D1
- SQLite
- PWA

## ✨ Fitur Utama

| Modul | Keterangan |
|---------|---------|
| 👳 Manajemen Santri | Biodata, wali, status aktif |
| 👨‍🏫 Manajemen Guru | Data pengajar dan jadwal |
| 📚 Akademik | Kelas, nilai, rapor |
| 📿 Tahfidz | Monitoring hafalan |
| 📱 Absensi QR | Kehadiran berbasis QR |
| 💰 Keuangan | Kas, infaq, donasi |
| 📄 Administrasi | Surat dan arsip |
| 📖 Perpustakaan | Peminjaman buku |
| 🏠 Asrama | Kamar dan inventaris |
| 🎥 Media Dakwah | Artikel dan dokumentasi |
| 📊 Dashboard | Statistik dan laporan |
| 🔐 Role Management | Hak akses pengguna |
